# BONDINGS 2.0 — Native Android UI starter

A native Android (Kotlin Views) prototype with:
- Dark purple/pink BONDINGS styling
- 3-column Discover grid and tappable demo profiles
- Bottom navigation: Discover, Likes, Chat, Plans, Profile
- Free, Plus and Premium plan presentation
- In-app navigation and prototype feedback

## Build
Use JDK 17 and Android Gradle Plugin 8.7.3 / Gradle 8.9.
Run `gradle assembleDebug`.

## Important
This is a UI prototype, not a production dating app. The profiles are demo placeholders, not real member photos.
Authentication, Supabase profile loading, photo upload/storage, real chat, safety/moderation, push notifications, and Google Play Billing are not connected yet. Paid plan buttons do not charge users. Do not publish as a production app until these integrations, privacy/security review, and release signing are complete.
